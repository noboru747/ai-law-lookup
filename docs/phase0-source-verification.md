## 逐項補充

### 1. 消費者保護法

- 全國法規資料庫頁面標示「修正日期：民國 104 年 06 月 17 日」，Open API 的 `LawModifiedDate` 為 `20150617`，兩者一致。
- 沿革：1994-01-11 制定，2003-01-22、2015-06-17 修正（中間另有組織改造相關公告）。
- 規格書所列內容的條文位置（核對時確認存在）：第 2 條（定義，含通訊交易、訪問交易）、第 17 條（中央主管機關得公告定型化契約應記載或不得記載事項）、第 19 條（通訊交易或訪問交易七日解除權，第 2 項授權行政院定合理例外情事）。
- 申訴與調解流程：消保法同章節。另有命令「消費爭議調解辦法」（pcode J0170008，2013-09-18 修正）可補足調解程序，**建議列入候選**，是否納入待決定。

### 2. 消費者保護法施行細則

- 建議納入：與解除權（第 17、18 條）、定型化契約（第 12～15 條）直接相關，篇幅不大。
- 規格書備註提到「通訊交易定義相關」：通訊交易之定義在消保法第 2 條第 10 款，施行細則沒有另行定義，納入理由應改為上述各條。

### 3. 通訊交易解除權合理例外情事適用準則

- 只有 4 條，內容完整可入庫。第 2 條列出多款例外商品／服務（易腐敗、客製化、報紙期刊雜誌、拆封影音商品或電腦軟體、非以有形媒介提供之數位內容等），各款原文以 Phase 1 抓取結果為準。

### 4. 禮券

## 開放資料取得方式

### 全國法規資料庫 Open API（適用：消保法、施行細則、準則）

- 文件：https://law.moj.gov.tw/api/swagger/index.html ；OpenAPI JSON：https://law.moj.gov.tw/api/swagger/docs/v1 （標題「全國法規資料庫 OpenAPI」，資料更新時間 2026/10/22）。
- 下載端點（皆為 GET，回傳 ZIP）：
  - 中文法律：`https://law.moj.gov.tw/api/ch/law/json`（亦有 `/xml`），壓縮約 6.1 MB，解壓後 `ChLaw.json` 約 26 MB，共 1,351 部法律。
  - 中文命令：`https://law.moj.gov.tw/api/ch/order/json`（亦有 `/xml`），壓縮約 25.8 MB，`ChOrder.json` 共 10,453 筆命令。
  - 英文版：`/api/en/law/{json|xml}`、`/api/en/order/{json|xml}`。
- ZIP 內容：資料檔、`manifest.csv`、`schema.csv`。
- 資料檔頂層結構：`{"UpdateDate": "2026/10/22 上午 12:00:00", "Laws": [...]}`。檔案為 UTF-8 含 BOM，讀取請用 `utf-8-sig`。
- 每部法規欄位（依 `schema.csv`）：`LawLevel`（位階）、`LawName`、`LawURL`（含 pcode）、`LawCategory`、`LawModifiedDate`（YYYYMMDD，法規異動日期）、`LawEffectiveDate`、`LawEffectiveNote`、`LawAbandonNote`（廢止註記）、`LawHasEngVersion`、`EngLawName`、`LawAttachements`、`LawHistories`（沿革全文）、`LawForeword`、`LawArticles`。
- 條文欄位：`ArticleType`（`A` 條文、`C` 章節標題）、`ArticleNo`（如 `第 19 條`、`第 19-1 條`）、`ArticleContent`（條內以 `\r\n` 分款）。
- 對照需求：
  - 條號：有（`ArticleNo`）。
  - 修正日期：僅法規層級有 `LawModifiedDate`，沒有逐條修正日期；逐條修正需自 `LawHistories` 沿革文字解析，Phase 1 決定做不做。
  - 章節：以 `ArticleType = C` 的獨立項目呈現（如「第 一 章 總則」），需依出現順序指派給後續條文。
  - 條層級來源 URL：法規層級有 `LawURL`；條層級連結的格式本次未驗證，Phase 1 實測後再採用。
- 授權：「政府網站資料開放宣告」採政府資料開放授權條款第 1 版，可無償使用、改作、再散布，**使用時應註明出處**，且不得惡意變更資訊。需在 README 與資料 metadata 註明出處「全國法規資料庫」。
- 更新頻率：網站說明內容每週五定期更新；本次核對時資料截止日為 2026-10-22。
- 抓取禮儀：本次核對中法律檔與命令檔各只下載 1 次。Phase 1 的抓取腳本須快取原始 ZIP 到 `data/raw/`，不要重複下載。
- 技術備註：全國法規資料庫的憑證在 Python 3.14 預設嚴格驗證下會報 `Missing Subject Key Identifier` 而失敗（本次以 `curl` 下載解決）。Phase 1 抓取腳本需處理（例如改用 curl，或明確指定 CA），不建議關閉憑證驗證。
- 網站 HTML 頁面可能以 Big5 相容編碼回傳，不是 UTF-8；改用 Open API 則無此問題。

### 定型化契約應記載及不得記載事項（適用：禮券、健身中心）

- 這類公告不在全國法規資料庫 Open API 內（在命令檔搜尋「應記載」「禮券」「健身」「定型化」僅得到無關的營繕工程承攬契約應記載事項實施辦法等）。
- 官方彙整頁：行政院全球資訊網 https://www.ey.gov.tw/Page/2285E9A14973DE75 （「定型化契約應記載及不得記載事項」，核對時共 88 筆、6 頁，支援 `?page=N&PS=15` 分頁）；消保處入口頁 https://cpc.ey.gov.tw/Page/6A1E96411F78365C （「法規及定型化契約」）。
- 每筆公告有獨立頁面（含公告沿革、令號）與附件，附件下載為 `https://www.ey.gov.tw/File/<id>?A=C`。
- 格式：
  - 禮券：ODT（解壓取 `content.xml` 即可抽文字，已驗證）與 PDF。PDF 以 pdftotext 抽出為亂碼，需改用 ODT 或 PyMuPDF。
  - 健身中心：只有 PDF，PyMuPDF 可抽出正確中文（已驗證）；若日後格式變化，退路為 OCR 或告知使用者手動複製（規格 4.1 第 3 順位）。
- 此來源屬規格 4.1 第 2 順位。列表與詳細頁為伺服器端渲染 HTML，一般 HTTP GET 即可取得，不一定需要 Playwright。
- 本次核對僅對行政院網站發出少量請求（列表頁 7 次、詳細頁與附件各數次）。Phase 1 抓取時須限制頻率；本次只逐字讀過全國法規資料庫的開放宣告，行政院網站的使用條款（頁尾「政府網站資料開放宣告」）尚未逐字核對，抓取前需再讀一次。

## 結論與建議

1. 5 項候選皆可查得官方來源，**無須刪除任何一項**。
2. 名稱修正 1 項：禮券改為「商品(服務)禮券定型化契約應記載及不得記載事項」；且禮券只有單一合併版本，不存在多個行業別版本。
3. 施行細則建議納入；可另考慮納入「消費爭議調解辦法」（J0170008）以支撐「消費申訴流程」葉節點。
4. 開放資料可涵蓋消保法、施行細則、準則三者（結構化 JSON/XML）；兩份行業別公告需走行政院網站（ODT／PDF），解析難度較高，且以「點」為單位。
5. 快照日 2026-11-01 可用，見 [ADR 0005](decisions/0005-snapshot-date.md)。
